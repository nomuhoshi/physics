# 04 古典近似与能量均分

## 古典分配関数
$$z = \frac{1}{h^f}\int e^{-\beta H(p,q)}\,d^fp\,d^fq,\qquad Z_{\rm CSM} = \frac{1}{(2\pi\hbar)^{3N}N!}\int e^{-\beta H}\prod d^3p_i\,d^3r_i$$
- CSM = Classical Statistical Mechanics
- 除以 h^f：每个量子状态在相空间占面积 h（周期境界条件 ΔxΔp = h 可验证）
- 能量连续时求和换成积分

## 哈密顿量
用 p 和 x 写的总能量：H = 动能（含 p²）+ 势能（含 x² 等）。
- 动能 ½mv² = p²/2m；弹簧势能 ∫kx dx = ½kx²（小振动 = 调和近似）
- 项相加 ⇒ e^{−βH} 拆成乘积 ⇒ 各项可单独积分

## 理想气体
- 动量：∫e^{−βp²/2m}dp = √(2πmk_BT)（三方向立方）；位置：V
$$z_1 = V\Big(\frac{2\pi mk_BT}{h^2}\Big)^{3/2} = \frac{V}{\lambda_T^3},\qquad Z = \frac{z_1^N}{N!}$$
- 除 N!：同种粒子不可分辨，交换不产生新状态
- F = −Nk_BT[log(V/Nλ_T³) + 1]，p = Nk_BT/V
- μ = −k_BT log(V/Nλ_T³) = k_BT log(nλ_T³)（对 F 求导时乘积法则的 +k_BT 与 −Nk_BT 的 −k_BT 抵消）

## 熱的ドブロイ波長
$$\lambda_T = \frac{h}{\sqrt{2\pi mk_BT}}\propto T^{-1/2}$$
- 单位：mk_BT 是 kg²m²s⁻²，h² 是 kg²m⁴s⁻²，相除剩 m⁻²，所以 λ_T 是长度
- 意义：热运动下粒子的德布罗意波长；V/λ_T³ ≈ 可用量子状态数
- 古典近似成立：nλ_T³ ≪ 1（热波长 ≪ 粒子间距）
- 例：氦、300 K，λ_T ≈ 0.5 Å

## 高斯积分
$$\int_{-\infty}^{\infty}e^{-ax^2}dx = \sqrt{\frac{\pi}{a}},\qquad \int x^2e^{-ax^2}dx = \frac{1}{2a}\sqrt{\frac{\pi}{a}}$$
证明（極座標）：I² = ∫∫e^{−a(x²+y²)}dxdy，0≤r<∞，0≤θ<2π，I² = ∫∫e^{−ar²} r dr dθ = π/a ⇒ I = √(π/a)（ガウス積分）

## 能量均分定理
一般形式：**x^n 项贡献 k_BT/n**。证明：
$$\int e^{-\beta a q^n}dq\propto\beta^{-1/n}\ \Rightarrow\ \langle aq^n\rangle = -\frac{\partial\log Z_q}{\partial\beta} = \frac{1}{n\beta}$$
- 其他项在分子分母约掉，所以可以逐项算；与系数 a 无关

| 项 | n | 贡献 |
|--|--|--|
| p²/2m、½m ω²x² | 2 | k_BT/2 |
| bx⁴ | 4 | k_BT/4 |
| bx⁶ | 6 | k_BT/6 |
| mgz | 1 | k_BT |

成立条件：古典（能量连续）。量子域（k_BT ≲ ℏω）不成立，有零点能。

## 杜隆-珀蒂
3N 个振子 × 2 个二次项 × ½k_BT ⇒ E = 3Nk_BT，C = 3Nk_B = 3R ≈ 25 J/(mol·K)
