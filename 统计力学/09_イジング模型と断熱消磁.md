# 09 イジング模型と断熱消磁（統計力学B 第B4回）

主线：**热力学第三定律（T→0 で S→0）为什么成立**。

## 需要接受的三条设定
1. σ_i = ±1（上/下），N 个原子共 2^N 种排列
2. 外磁场：ε_σ = −μHσ（顺着磁场能量低），h ≡ μH
3. 相邻相互作用：−Jσ_iσ_{i+1}（J>0 強磁性：同向低；J<0 反強磁性；J：交換相互作用）

σ 是变量（对它求和），h、J 是常数。

### −Jσσ 的来源
无外场时，同时翻转所有自旋能量不变 ⇒ 一对自旋只有"同向/反向"两个能量。σ_iσ_{i+1} = ±1 正好区分两者，所以 E = a + bσ_iσ_{i+1}；去掉常数，J ≡ (E_反 − E_同)/2。物理上是 Heisenberg 模型 −J S_i·S_j 只保留 z 分量。

## ① 理想常磁性体（无相互作用）
$$z_1 = 2\cosh(\beta\mu H),\quad F = -Nk_BT\log[2\cosh(\beta\mu H)]$$
$$S = Nk_B[\log(2\cosh x) - x\tanh x],\quad x = \frac{\mu H}{k_BT}$$
- 熵只依赖 μH/T
- H≠0，T→0：log(2cosh x) = x + log(1+e^{−2x}) ≈ x + e^{−2x}；x tanh x ≈ x − 2xe^{−2x} ⇒ S ≈ Nk_B(1+2x)e^{−2x} → 0
- **H=0：S = Nk_B log 2，与温度无关 ⇒ 第三定律不成立**（2^N 重縮重）
- 现实中不成立：真实固体必有相互作用；只在 k_BT ≫ J 时是好近似（断热消磁利用这个窗口）
- 磁化 ⟨m⟩ = μ tanh(βμH)，M = N⟨m⟩；磁化率 χ = (∂M/∂H)_{H=0} = Nμ²/k_BT（**キュリーの法則**，tanh x ≈ x）

## ② 相互作用は基底状態の縮重を減らす
4 个自旋（正方形 4 条键），J<0：无相互作用时 16 个状态同能量；有相互作用时只有 ↑↓↑↓、↓↑↓↑ 最低 ⇒ **縮重 16 → 2**。

## ③ 2スピン系
| σ₁σ₂ 状态 | σ₁+σ₂ | σ₁σ₂ |
|--|--|--|
| ↑↑ | 2 | 1 |
| ↑↓ / ↓↑ | 0 | −1 |
| ↓↓ | −2 | 1 |
- 只有磁场：z = 2 + 2cosh 2βh = (2cosh βh)²（独立，因式分解；用 cosh 2x = 2cosh²x − 1）
- 只有相互作用：z = 4cosh βJ（不能写成平方）
- 两者都有：z = 2e^{βJ}cosh 2βh + 2e^{−βJ}
- 关键性质：固定 σ₁ 后对 σ₂ 求和得 2cosh βJ，与 σ₁ 的方向无关

## ④ 1次元イジング模型
E = −J Σ_{i=1}^{N−1} σ_iσ_{i+1}（最近接のみ、N−1 条键）
- 从 σ_N 开始逐个求和，每次得常数 2cosh βJ，共 N−1 次，最后 σ₁ 两种：
$$Z_{\rm Ising} = 2(2\cosh\beta J)^{N-1} = 2(e^{\beta J}+e^{-\beta J})^{N-1}$$
- 另一种看法：键变量 τ_i = σ_iσ_{i+1} = ±1，相互作用消失，变成 N−1 个独立 2 準位系
- 只适用于 1 维；2 维要 Onsager。1 次元厳密解に相転移なし，2 次元は相転移あり
- ⟨σ_iσ_{i+1}⟩ = tanh βJ；⟨E⟩ = −(N−1)J tanh βJ
  - β→∞（低温）：→ 1，相邻自旋对齐；β→0（高温）：→ 0，无关联

## ⑤ 自由エネルギー
$$F = -k_BT[\log 2 + (N-1)\log(2\cosh\beta J)]\approx -Nk_BT\log(2\cosh\beta J)$$
- 低温 k_BT ≪ J：F ≈ −NJ − Nk_BTe^{−2J/k_BT} → F = E = −NJ，S = 0
- 高温 k_BT ≫ J：F = −Nk_BT log 2
- 不近似时 S(T→0) = k_B log 2（全上/全下二重縮重），但 S/N → 0，宏观可忽略

## ⑥ 内部磁場
$$S_{\rm Ising} = Nk_B\Big[\log(2\cosh\tfrac{J}{k_BT}) - \tfrac{J}{k_BT}\tanh\tfrac{J}{k_BT}\Big]$$
与理想常磁性体的 S 比较：μH → J。J が磁場と同様な効果を持つ ⇒ **内部磁場**。外部磁場がなくても内部磁場により T→0 で S→0。

## ⑦ 断熱消磁
- 断熱：S 一定，S(T₁,B₁) = S(T₂,B₂)；理想常磁性体の S は B/T の関数 ⇒
$$\frac{B_1}{T_1} = \frac{B_2}{T_2}\ \Rightarrow\ T_2 = \frac{B_2}{B_1}T_1 < T_1$$
- B=0 まで下げても内部磁場があるので
$$T_0 = \frac{B_{\rm int}}{B_1}T_1$$
  までしか下がらない
- 低温到达：B_int 小（相互作用の小さな磁性体）、B₁ 大、T₁ 低
- 核磁気モーメントは電子の約 1/2000 ⇒ 内部磁場が弱い ⇒ **核断熱消磁はより低温に到達**
- 原理は気体の断熱膨張と同じ（S を一定に保ち温度以外の変数を変える）
- 繰り返せば絶対零度にいくらでも近づけるが、有限回では到達できない
