# 03 热力学关系与涨落

## F = −k_BT log Z（两种推法）

**方法1：直接代入熵（简洁）**
P_n = e^{−βE_n}/Z，log P_n = −log Z − βE_n，代入吉布斯熵：
$$S = k_B\log Z + \frac{E}{T}\ \Rightarrow\ -k_BT\log Z = E - TS = F$$

**方法2：ルジャンドル変換（题目要求时用）**
- 无次元熵 Ŝ = S/k_B = log Z + βE，∂Ŝ/∂E = β
- 把变量 E 换成 β：g(β) = βE − Ŝ(E) = −log Z
- βE − Ŝ = E/k_BT − S/k_B，两边乘 −k_BT ⇒ E − TS = −k_BT log Z

"マクロな関係式" 指热力学定义 F ≡ E − TS（来自 dE = TdS − pdV）。

## 其他关系
$$S = -\Big(\frac{\partial F}{\partial T}\Big)_V = k_B\beta^2\Big(\frac{\partial F}{\partial\beta}\Big)_V,\quad p = -\frac{\partial F}{\partial V},\quad \mu = \frac{\partial F}{\partial N},\quad G = F + pV$$

## カノニカル平衡 ⇔ F 最小
- 系+热浴孤立 ⇒ S_total 最大
- S_热浴 = S_热浴⁽⁰⁾ − E_系/T（热浴给出能量 E_系）
- S_total = S_系 − E_系/T + const 最大 ⇔ 乘 −T 后 F = E − TS 最小

## エネルギーとエントロピーの競合
F = E − TS：E 想变小（低能态），S 想变大（混乱）。低温 E 支配，高温 TS 支配，平衡在 F 最小点。

## 化学ポテンシャル
- dE = TdS − pdV + μdN，dF = −SdT − pdV + μdN ⇒ μ = (∂F/∂N)_{T,V}
- 也可写 ∂S/∂N = −μ/T
- 两系统交换粒子平衡：μ₁ = μ₂；粒子从高 μ 流向低 μ（类比热量从高 T 流向低 T）

## エネルギー揺らぎと比熱（考试必考）
1. σ² = ⟨E²⟩ − ⟨E⟩²
2. ⟨E⟩ = −∂logZ/∂β，⟨E²⟩ = (1/Z)∂²Z/∂β²
3. 乘积法则：∂²logZ/∂β² = −(1/Z²)(∂Z/∂β)² + (1/Z)∂²Z/∂β² = ⟨E²⟩ − ⟨E⟩² ⇒ σ² = −∂⟨E⟩/∂β
4. C = (∂E/∂β)(∂β/∂T) = −(1/k_BT²)∂E/∂β ⇒
$$\boxed{\sigma^2 = k_BT^2C}$$

**应用例**：E₁ = aT² ⇒ σ₁² = 2ak_BT³；E₂ = 3bT⁴ ⇒ σ₂² = 12bk_BT⁵；σ₂/σ₁ = T√(6b/a)

## 熱力学極限
理想气体 E = (3/2)Nk_BT，C = (3/2)Nk_B：
$$\frac{\sigma}{E} = \sqrt{\frac{2}{3N}}\propto\frac{1}{\sqrt N}\sim10^{-12}$$
- 用相对涨落：绝对涨落 σ ∝ √N 反而变大，但 E ∝ N 增长更快
- 结论：マクロ系ではエネルギー揺らぎが無視でき、ミクロカノニカルとカノニカルが同じ熱力学を与える
