# 07 固体比热：杜隆-珀蒂 → 爱因斯坦 → 德拜

## 故事线（可用于视频）
1. **杜隆-珀蒂（1819）**：很多固体摩尔比热 ≈ 25 J/(mol·K) = 3R。能量均分也给出 3Nk_B，室温成立
2. **低温失效**：实验比热下降趋于 0（金刚石室温已偏低）。经典理论只会说常数；第三定律也要求 C → 0
3. **爱因斯坦（1907）**：振动能量量子化、3N 个振子同频 ω_E。高温 → 3Nk_B，低温下降。量子论首次用于固体
4. **再次失效**：实验低温是 T³，爱因斯坦是指数衰减，降得太快。原因：忽略了原子耦合产生的低频模式
5. **德拜（1912）**：连续弹性体，D(ω) ∝ ω²，截断在 ω_D。低温 T³，高温 3Nk_B

核心画面：一张 C–T 图上依次叠加 经典水平线 / 实验 / 爱因斯坦 / 德拜。

## 固体比热、格子比热
C_V = ∂E/∂T。固体热能主要储存在原子振动（格子振動）中，其贡献叫格子比熱（金属还有电子比热 ∝ T）。

## 爱因斯坦模型
- z₁ = 1/[2sinh(ℏω_E/2k_BT)]，Z = z₁^{3N}（局在）
- log Z 两项分别对 β 求导再合并：E = 3Nℏω[½ + 1/(e^{βℏω}−1)]（零点能 + 热激发能）
- 零点能对 T 求导为 0；x = ℏω/k_BT = θ_E/T，dx/dT = −x/T：
$$C = 3Nk_B\,x^2\frac{e^x}{(e^x-1)^2},\qquad \theta_E = \frac{\hbar\omega_E}{k_B}$$
- 高温 x → 0：(e^x−1)² ≈ x² ⇒ C → 3Nk_B
- 低温 x → ∞：(e^x−1)² ≈ e^{2x} ⇒ C ≈ 3Nk_Bx²e^{−x}（指数压倒 x²）
- 数值 C/3Nk_B：x=0.1→0.999，1→0.921，2→0.724，5→0.174，10→0.00045

## 波的基础
- u = A cos(kx − ωt)：k = 2π/λ（波数），ω = 2πν（角振動数，rad/s）
- 波峰 kx − ωt = 0 ⇒ x = (ω/k)t ⇒ 波速 s = ω/k = νλ
- **分散関係** ω(k)；ω = sk 为线性（デバイの仮定 = (あ)）
- 縦波 longitudinal：位移 ∥ 传播方向；横波 transverse：位移 ⊥ 传播方向
- 固体每个 k 有 1 纵 + 2 横 = 3 种偏振（s_l, s_t）

## 状態密度 D(ω)
D(ω)dω = 角振動数在 ω∼ω+dω 的模式数（频率近连续，只能数小区间；个数 ∝ 区间宽度）。

推导（考试要写）：
1. 周期境界条件（首尾相接成圈，装下整数个波长）：k = (2π/L)(n_x, n_y, n_z)
2. 波数空间格点间距 2π/L，每个格点独占 (2π)³/V（小立方体无缝铺满）
3. 一个格点 = 一个允许的 k = 一种偏振的一个模式
4. 球壳 4πk²dk 里格点数 Vk²dk/2π²
5. ω = sk：一种偏振 **V ω²/(2π²s³)**（值得记住）
6. 三种偏振，1/s̄³ ≡ ⅓(1/s_l³ + 2/s_t³)：
$$(A)\quad D(\omega) = \frac{3V}{2\pi^2\bar s^3}\omega^2$$

## デバイ截断
- (い) 振子总数 3N（N 原子 × 3 方向）
- ∫₀^∞ ω²dω 发散；短波长下连续体近似失效 ⇒ 截断 ∫₀^{ω_D}D dω = 3N
$$(B)\quad \omega_D = \bar s\Big(\frac{6\pi^2N}{V}\Big)^{1/3}$$
- 由 V/(2π²s̄³) = 3N/ω_D³：
$$(う)\ D = \frac{9N\omega^2}{\omega_D^3}\ (0<\omega<\omega_D),\qquad (え)\ 0\ (\omega>\omega_D)$$

## デバイ比熱
- 模式独立，比热相加，按频率分组：C = ∫₀^{ω_D} D(ω)c(ω)dω，c(ω) = k_Bx²e^x/(e^x−1)²
- 爱因斯坦是特例：D = 3Nδ(ω − ω_E) ⇒ C = 3Nc(ω_E)
- 换元 x = ℏω/k_BT，θ_D = ℏω_D/k_B，ω²dω/ω_D³ = (T/θ_D)³x²dx：
$$C = 9Nk_B\Big(\frac{T}{\theta_D}\Big)^3\int_0^{\theta_D/T}\frac{x^4e^x}{(e^x-1)^2}dx$$
- 低温：上限 → ∞，积分 = 4π⁴/15 ⇒ **C ≈ (12π⁴/5)Nk_B(T/θ_D)³**（只有 ℏω ≲ k_BT 的低频模式被激发，个数 ∝ T³）
- 高温：被积函数 ≈ x²，积分 = (θ_D/T)³/3 ⇒ C → 3Nk_B

| | 低温 | 高温 |
|--|--|--|
| 爱因斯坦 | e^{−θ_E/T} ✗ | 3Nk_B ✓ |
| デバイ | T³ ✓ | 3Nk_B ✓ |
