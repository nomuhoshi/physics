# 08 相互作用のある希薄気体（統計力学B 第B1回）

## Z = Z_理 × Z_相
- H = K + U，K = Σ p_i²/2m（只含动量），U = Σ_{i<j} v(R_ij)（只含位置）
- i<j：每对只算一次，共 N(N−1)/2 = C(N,2) 对（有序 N(N−1)，每对重复 2 次）
- e^{−β(K+U)} = e^{−βK}e^{−βU}，积分分离：
$$Z_{\rm CSM} = \frac{1}{N!}\Big(\frac{mk_BT}{2\pi\hbar^2}\Big)^{3N/2}Q_N,\qquad Q_N = \int e^{-\beta U}\prod d^3r_i$$
- U = 0 时 Q_N = V^N 回到理想气体；Z_相 ≡ Q_N/V^N
- F = F₀ + F_分；相互作用只改变位置分布，不影响速度分布

## 分子间势能
典型形状：レナード＝ジョーンズ（L-J）ポテンシャル。R 小强斥力（电子云重叠，泡利），中距离负的"坑"（引力），R 大 → 0。
- **硬芯**：把近距离斥力理想化为无限高墙 v = ∞（R<d），粒子像直径 d 的硬球

## メイヤーのf関数
$$1 + f_{ij} = e^{-\beta v(R_{ij})},\qquad f = e^{-\beta v}-1$$
- 远处 f = 0；硬芯内 f = −1；引力区 f > 0（小）
- 希薄：绝大多数粒子对离得远，e^{−βv} ≈ 1，所以把偏离 1 的部分提出来
- 不能对 e^{−βv} 泰勒展开：硬芯处 βv = ∞；f 有限且只在小范围内非零
- ∏(1+f_ij) = 1 + Σf_ij + Σf_ijf_kl + …（几个粒子同时靠近）

## クラスター展開
- 1 项 → V^N
- 一对 f_12：V^{N−2}∫∫f(|r₂−r₁|)d³r₁d³r₂ = V^{N−1}∫f d³R（相对坐标）
- 共 ≈ N²/2 对：Q_N ≈ V^N[1 + (N²/2V)∫f d³R]
- 定义第2ビリアル係数：
$$B \equiv -\frac12\int f(R)d^3R\ \Rightarrow\ Q_N\approx V^N(1 - NnB)$$
- NnB 不小，要把"k 对各自独立靠近"的项都加上：第 k 项 V^N(−NnB)^k/k! ⇒
$$Q_N \approx V^Ne^{-NnB}$$
  （也保证 log Q_N 示量）
- F = F₀ + N²k_BT B/V
- 硬芯：B = ½·(4/3)πd³ = 2πd³/3 —— |B| 是分子力作用范围的体积量级
- 希薄 ⇔ n|B| ≪ 1

## ビリアル展開とファンデルワールス
$$\frac{pV}{Nk_BT} = 1 + nB + n^2C + \cdots$$
- 高温近似 B(T) = −2π∫f R²dR = b − a/k_BT
  - b：斥力（排除体积）效应；a：弱引力效应
$$\Big(p + \frac{N^2a}{V^2}\Big)(V - Nb) = Nk_BT$$
- b 与 1 次元硬芯的 L − Nd 是同一思想
