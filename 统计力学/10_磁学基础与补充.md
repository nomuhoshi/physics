# 10 磁学基础与补充

## 理解"磁针"的知识链
① 矢量与叉积 → ② 电荷与电场 F=qE → ③ 电流 I=dq/dt → ④ 洛伦兹力 F=qv×B（定义 B）→ ⑤ 安培定律 → ⑥ 力矩 → ⑦ 电流圈受力矩（定义磁矩）→ ⑧ U=−μ·B → ⑨ 磁针=磁気双極子 → ⑩ 角动量 → ⑪ μ∝L → ⑫ 自旋 → ⑬ シュテルン＝ゲルラッハ → ⑭ イジング変数

### ① 矢量
- 点积 a·b = ab cosθ（标量，同向程度）
- 叉积 |a×b| = ab sinθ，方向右手定则，垂直于两者；a×b = −b×a；x̂×ŷ = ẑ
- 物理里"结果垂直于两个原因"都用叉积：洛伦兹力、力矩、角动量

### ② 电荷与电场
库仑 F = kq₁q₂/r²；E ≡ F/q；电场对静止电荷也施力。

### ③ 电流
I = dq/dt = nqvA；**绕圈的电荷 = 电流 I = q/T = qv/2πr**。

### ④ 洛伦兹力
F = q(E + v×B)。磁力垂直速度 ⇒ 不做功；圆周运动 r = mv/qB；通电导线 F = IL×B。

### 磁铁（现象层面）
有 N、S 两极，同极相斥异极相吸，**切断后得两根完整磁铁（极不能单独存在）**。本质：内部电子自旋排列整齐（J>0）；高于キュリー温度（铁约 770°C）失去磁性。

### ⑤ 安培定律
- エルステッド（1820）：电流使磁针偏转
- 直导线 B = μ₀I/2πr，绕导线成圆、与圆相切
$$\oint\mathbf B\cdot d\mathbf l = \mu_0I_{\rm 内}$$
- **简单算法**：圆上 B 与路径同向、大小相同 ⇒ B × 2πr = μ₀I
- 分量写法：B = (μ₀I/2πr)·φ̂，φ̂ = (−y, x, 0)/r（把位置矢量逆时针转 90° = 切线方向 = ∂r/∂φ；单位矢量 = 矢量÷**自己的长度**，分母是 r 不是 φ）
  - 注意：写成 r̂ 是错的，那是点电荷电场的方向
- 路径形状无关（r 消掉）；不包围导线时为 0
- 螺线管 B = μ₀nI，外部磁场与条形磁铁相同 ⇒ 电流圈可以代替磁铁

### ⑥ 力矩
τ = r×F = rF sinθ = F × 力臂；τ = Iθ̈。**力偶**：等大反向不共线，合力 0 只转动，τ = F·d 且与转轴位置无关。

### ⑦ 电流圈 → 磁矩
长方形线圈：b 边力共线抵消，a 边形成力偶 τ = IAB sinθ。定义 **μ ≡ IA n̂** ⇒ τ = μ×B（与磁针完全相同）。

### ⑧⑨ 磁気双極子
- 磁荷模型 μ = q_m d；电流圈模型 μ = IA（更本质）；远处场相同（∝1/r³）
- 均匀场合力 0；U = −μB cosθ（对力矩做功积分）；不均匀场受力 μ ∂B/∂x
- 指南针：Iθ̈ = −μB sinθ，小角度简谐振动 ω = √(μB/I)，摩擦耗散后停在 θ=0；θ=π 不稳定

### ⑩⑪ 角动量与磁矩
L = r×p，dL/dt = τ；圆周运动 L = mvr。转圈电荷 μ = evr/2 ⇒ **μ = (e/2m)L**。

### ⑫ 自旋
电子内禀（天生固有）的角动量，不是真的自转。S_z = ±ℏ/2（沿测量轴的分量，z 轴通常取磁场方向）。μ = g(e/2m)S_z，g ≈ 2 ⇒ μ_B = eℏ/2m ≈ 9.27×10⁻²⁴ J/T。σ = S_z/(ℏ/2) = ±1。电子带负电，磁矩与自旋反向。

### ⑬ シュテルン＝ゲルラッハ（1922）
银原子束过不均匀磁场 ⇒ 屏上只有**两个点** ⇒ 电子磁针只有上下两种朝向，即 σ = ±1 的实验基础。

## 磁化功 A = ∫₀^M H·dM
1. 环形螺线管（トロイダル），平均周长 L（中心线周长），截面积 S，V = LS
2. 安培：HL = NI
3. 法拉第：电流变化 ⇒ 反电动势 N dΦ/dt（楞次定律：阻碍变化，像惯性）
4. 电源功率 I·N dΦ/dt = HL·S dB/dt ⇒ dA = H dB（单位体积）
5. CGS：B = H + 4πM ⇒ dA = H dH + 4πH dM
6. H dH = 真空场能量（无材料也需要，与材料无关）；H dM = 磁化功（材料内小磁针被排整齐）
7. 去掉真空部分 ⇒ A = ∫₀^M H dM（SI：B = μ₀(H+M)）

## 埃伦费斯特定理
$$\frac{d\langle A\rangle}{dt} = \frac{i}{\hbar}\langle[H,A]\rangle$$
- 推导用到 H 是厄米算符：∫(Hψ)*φ dx = ∫ψ*Hφ dx（令 φ = Aψ）。厄米 ⇒ 期待值为实数
- [p², x] = p[p,x] + [p,x]p = −2iℏp（**算符不交换，不能直接提公因子**，要插入 pxp）
- d⟨x⟩/dt = ⟨p⟩/m
- [f(x), p] = iℏf′(x)（对 xⁿ 数学归纳）⇒ d⟨p⟩/dt = −⟨∂V/∂x⟩
- 意义：期待值满足经典方程形式（对应原理）；只有 V 是二次以下时 ⟨V′(x)⟩ = V′(⟨x⟩)，波包中心严格走经典轨迹
- 波包：多个波数叠加成的局域波；有限持续的振动必含频率范围（傅立叶），ΔxΔk ≳ 1
