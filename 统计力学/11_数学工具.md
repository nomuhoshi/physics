## 拉格朗日乘数法
**问题**：带约束求极值（S 最大，但 P 必须满足归一化等约束）。

**几何直觉**（例：f = x+y，约束 x²+y² = 1）
- f = c 的等高线是斜率 −1 的平行直线 y = −x + c，c 越大越靠右上
- 最大值点一定**相切**：若直线穿过圆，圆的一部分在直线右上侧，沿圆走过去 f 更大，矛盾；碰不到圆则取不到
- 相切 ⇒ 两条曲线共切线 ⇒ 法线（梯度）平行：∇f = λ∇g
- 类比：沿固定小路爬山，最高点处小路只擦过等高线

**做法**：𝓛 = f − λ(g − c)，对所有变量和 λ 求偏导令其为 0（∂𝓛/∂λ = 0 自动还原约束）。约束几个，乘数几个。例题解：x = y = 1/√2，f_max = √2。

**乘数的意义**：λ = ∂f_max/∂c（目标函数对约束量的导数）⇒ 统计力学里乘数 = 1/T、−μ/T。

**对求和中某一项求偏导**：只有同名项含该变量，其余导数为 0；d(P log P)/dP = log P + 1。

## 等比数列
S_n = 1 + r + … + rⁿ；乘 r 再相减：S_n(1−r) = 1 − r^{n+1}
$$\sum_{n=0}^\infty r^n = \frac{1}{1-r}\quad(|r|<1)$$
r 换成 −u：1/(1+u) = 1 − u + u² − … ≈ 1 − u（u 小，每项小 100 倍量级）

## 泰勒展开
f(x) ≈ f(a) + f′(a)(x−a)，展开点必须离目标点近（热浴推导在 E_T 展开，因为 E_n ≪ E_T）。
- e^x ≈ 1 + x，log(1+u) ≈ u
- coth x ≈ 1/x + x/3（x 小）
- 1/(e^x−1) ≈ 1/x − 1/2（x 小）

## 双曲函数
cosh x = (eˣ+e⁻ˣ)/2，sinh x = (eˣ−e⁻ˣ)/2，tanh x = sinh/cosh
- cosh²x − sinh²x = 1，cosh 2x = 2cosh²x − 1，cosh(α+β) = coshα coshβ + sinhα sinhβ
- ½ + 1/(e^{2x}−1) = ½coth x
- log(2cosh x) = x + log(1+e^{−2x})
- tanh x = (1−e^{−2x})/(1+e^{−2x}) ≈ 1 − 2e^{−2x}（x 大）
- 极限：x→∞ 时 tanh → 1，x→0 时 tanh x ≈ x

## 伽马函数
Γ(z) = ∫₀^∞ t^{z−1}e^{−t}dt，Γ(n+1) = n!，Γ(z+1) = zΓ(z)
- ∫_{−∞}^{∞}e^{−u⁴}du = Γ(¼)/2 ≈ 1.8128；∫e^{−βbx⁶}dx = Γ(1/6)/[3(βb)^{1/6}]
- 不想用 Γ：换元 u = (βg)^{1/4}x，只需知道积分 ∝ β^{−1/n}，系数是常数，不影响能量和比热
- ∫₀^∞ x^p/(e^x−1) dx = p!ζ(p+1)；∫₀^∞ x⁴eˣ/(eˣ−1)² dx = 4π⁴/15

## 偶函数/奇函数
偶函数 × x = 奇函数；奇函数在对称区间积分为 0 ⇒ 偶势中 ⟨x⟩ = 0。
