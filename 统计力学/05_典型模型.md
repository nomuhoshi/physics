# 05 典型模型

## 準位系
"N準位系" = 每个粒子只能取 N 个离散能级。有縮重度 g 时，该能级的玻尔兹曼因子乘 g。
- 縮重度：同一能量对应几个状态。**基底状態の縮重度**决定 S(T→0) = k_B log(縮重度)
- 粒子是"部分系"（用编号区分）⇒ 局在，Z = z₁^N

| 系统 | z₁ | E |
|--|--|--|
| 2準位 (−ε, ε) | 2cosh βε | −Nε tanh(βε) |
| 3準位 (−ε, 0, ε) | 1 + 2cosh βε | −2Nε sinhβε/(1+2coshβε) |
| 3準位 縮重 5,2,5（±aε,0） | 2 + 10cosh βaε | −10Naε sinhβaε/(2+10coshβaε) |
| 3準位 縮重 3,5,3 | 5 + 6cosh βε | −6Nε sinhβε/(5+6coshβε) |

### 2準位比熱（−ε, ε）
$$C = Nk_B\Big(\frac{\varepsilon}{k_BT}\Big)^2\frac{1}{\cosh^2(\varepsilon/k_BT)}$$

### ショットキー比熱（0 縮重1, Δ 縮重 g）
$$z_1 = 1+ge^{-\beta\Delta},\quad E = \frac{Ng\Delta e^{-\beta\Delta}}{1+ge^{-\beta\Delta}},\quad C = \frac{Ng\Delta^2}{k_BT^2}\frac{e^{-\beta\Delta}}{(1+ge^{-\beta\Delta})^2}$$
- k_BT ≪ Δ：指数衰减到 0（冻结在基态）
- k_BT ≫ Δ：∝ 1/T² 衰减（布居已趋于饱和）
- 中间有峰：ショットキー異常（有限能级系统特有）

### 3準位常磁性体 E_i = −μ₀Hσ_i + Dσ_i²（σ=−1,0,1）
$$z_1 = 1 + 2e^{-\beta D}\cosh(\beta\mu_0H),\quad \langle m\rangle = \frac{2\mu_0e^{-\beta D}\sinh\beta\mu_0H}{1+2e^{-\beta D}\cosh\beta\mu_0H}$$
$$\chi = \frac{2\mu_0^2e^{-D/k_BT}}{k_BT(1+2e^{-D/k_BT})}$$

### 微正则版 2 準位（−ε, ε，n₋ 个在 −ε）
- W = N!/(n₋!n₊!)，E = ε(n₊ − n₋)，S = k_B log W（斯特林）
- 1/T = ∂S/∂E ⇒ n₋ = N e^{βε}/(2coshβε)，E = −Nε tanh βε
- 低温 n₋ → N，高温 n₋ → N/2
- 3準位微正则：用拉格朗日乘数法（约束 n₋+n₀+n₊ = N，能量固定）得同一结果

## 量子调和振子
能级 (n+½)ℏω，等比数列求和：
$$z_1 = \frac{e^{-\beta\hbar\omega/2}}{1-e^{-\beta\hbar\omega}} = \frac{1}{2\sinh(\beta\hbar\omega/2)}$$
$$E = N\hbar\omega\Big(\frac12+\frac{1}{e^{\beta\hbar\omega}-1}\Big) = \frac{N\hbar\omega}{2}\coth\frac{\hbar\omega}{2k_BT}$$
$$C = Nk_B x^2\frac{e^x}{(e^x-1)^2},\quad x = \frac{\hbar\omega}{k_BT}$$
- F = Nk_BT log[2 sinh(ℏω/2k_BT)]（F 用 log sinh，不能用 coth）
- 3 次元等方：指数 N → 3N；高温 E → 3Nk_BT（coth x ≈ 1/x + x/3）
- 量子效应温度：ℏω = k_BT_c（能级间隔 vs 热涨落）
- 结晶原子室温振动频率量级：k_BT/h ≈ 6 THz

## 非調和振動子 v = fx² + gx⁴（或 ax² + bx⁶）
- 切换点：fx₀² = gx₀⁴ ⇒ x₀ = √(f/g)，k_BT₀ ∼ f²/g（代入 gx₀⁴ 也一样）
- 积分主要贡献区：v(x) ∼ k_BT
- T_c ≤ T ≪ T₀（调和项主导）：z₁ = (πk_BT/h)√(2m/f)，C = Nk_B
- T ≫ T₀（x⁴ 主导）：∫e^{−βgx⁴}dx = Γ(¼)/[2(βg)^{1/4}]，z₁ ∝ T^{3/4}，C = ¾Nk_B
- x⁶ 主导：∫e^{−βbx⁶}dx = Γ(1/6)/[3(βb)^{1/6}]，z₁ ∝ T^{2/3}，C = ⅔Nk_B
- T ≤ T_c：量子调和振子（ω = √(2f/m)），C → 0
- ⟨x⟩ = 0（偶势 ⇒ x·e^{−βv} 奇函数）
- ⟨x²⟩：调和区 k_BT/2a；x⁴ 区 [Γ(¾)/Γ(¼)]√(k_BT/b)
- 二准位近似 E_n = ℏω(n+½) + α(n+½)²：Δ = ℏω + 2α，U = E₀ + Δ/(e^{βΔ}+1)，T_A ∼ m²ω⁴/(4λk_B)

## 硬芯 1 次元気体
- v = ∞（|X|<d），0（|X|≥d）；只有相邻 N−1 对相互作用
- 有效长度 L − Nd（不能先求 z₁ 再取 N 次方，粒子不独立）
- Z = (L−Nd)^N(2πmk_BT)^{N/2}/(N!h^N)，p = −∂F/∂L = Nk_BT/(L−Nd)

## 重力场中的理想气体
- 位置积分：S·∫₀^∞ e^{−βmgz}dz = Sk_BT/mg
- ⟨mgz⟩ = k_BT（一次项，比二次项多一倍）
- 3 mol ⇒ N = 3N_A

## 回転分子（2 原子）
- v² = a²(θ̇² + sin²θ φ̇²)，K = (I/2)(θ̇² + sin²θ φ̇²)，I = m₁a₁² + m₂a₂²
- p_θ = Iθ̇，p_φ = I sin²θ φ̇，H = (p_θ² + p_φ²/sin²θ)/2I
- z = 2Ik_BT/ℏ²，ε = k_BT（2 自由度）

## 超相対論気体 ε = cp
∫e^{−βcp}d³p = 8π/(βc)³ ⇒ z₁ = 8πV(k_BT)³/(h³c³)，S = Nk_B[log(8πV(k_BT)³/(Nh³c³)) + 4]
