# 06 吸着問題（ラングミュア吸着等温式）

N 个理想气体分子、N₀（或 M）个吸着サイト，N ≫ N₀ ≫ 1，每个サイト最多 1 个，吸着后能量比自由状态低 ε。

## (1) 吸着相
- 从 N₀ 个サイト中选 N_a 个：W = C(N₀, N_a)，每种排列能量都是 −N_aε
$$Z_a = \binom{N_0}{N_a}e^{N_a\beta\varepsilon}$$
$$F_a = -k_BT[N_0\log N_0 - N_a\log N_a - (N_0-N_a)\log(N_0-N_a)] - N_a\varepsilon$$

## (2) 气相（粒子数 N − N_a，"粒子数に注意して"）
$$Z_{\rm ideal} = \frac{1}{(N-N_a)!}\Big(\frac{V}{\lambda_T^3}\Big)^{N-N_a}$$
$$F_{\rm ideal} = -(N-N_a)k_BT\Big[\log\frac{V}{(N-N_a)\lambda_T^3}+1\Big]$$

## (3) 平衡：∂F_total/∂N_a = 0 ⇔ μ_a = μ_gas
- F_ideal 是 (N−N_a) 的函数，链式法则多一个负号 ⇒ ∂F_a/∂N_a = ∂F_ideal/∂(N−N_a)
- μ_a = k_BT log[N_a/(N₀−N_a)] − ε（+1 与 −1 抵消）
- μ_gas = −k_BT log[V/((N−N_a)λ_T³)]（"+1" 项的 +k_BT 与 −k_BT 抵消，没有多余 k_BT）
- N ≫ N_a ⇒ N − N_a ≈ N
$$\frac{N_a}{N_0} = \frac{x}{1+x},\qquad x = \frac{N}{V}\lambda_T^3e^{\varepsilon/k_BT}$$

## 用比值 Q(n+1)/Q(n) 的另一种做法
- Q(n) = Z_a(n)Z_gas(N−n)
- Q(n+1)/Q(n) = (M−n)(N−n)/(n+1) · (λ_T³/V) · e^{βε}
- 最确值处比值 ≈ 1，θ = n̄/M，ρ_g = (N−n̄)/V：
$$\frac{\theta}{1-\theta} = \rho_g\lambda_T^3e^{\varepsilon/k_BT}$$
- p = ρ_gk_BT ⇒ θ = K(T)p/[1+K(T)p]，K(T) = λ_T³e^{ε/k_BT}/k_BT

## 极限与物理
- K p ≪ 1（低压）：θ ≈ Kp，线性
- K p ≫ 1（高压）：θ → 1，饱和
- 低温：エネルギー（−ε）支配 → 吸着多；高温：エントロピー（気体の自由度）支配 → 吸着少
- 平衡 = F_total 最小点
