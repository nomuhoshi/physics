# 02 统计集团

答题时每个集团写 (a) 什么样的系 (b) 概率分布 (c) 完全熱力学関数（括号里写3个自然变量）(d) 平衡如何决定。

| 集团 | 固定 | 可变 | 分布 | 完全熱力学関数 | 平衡 |
|--|--|--|--|--|--|
| ミクロカノニカル | E,V,N | — | p_i = 1/W(E) | S(E,V,N) = k_B log W | S 最大 |
| カノニカル | T,V,N | E | e^{−βE_n}/Z | F(T,V,N) = −k_BT log Z | F 最小 |
| T-p（等温等圧） | T,p,N | E,V | e^{−β(E_n+pV)}/Δ | G(T,p,N) = −k_BT log Δ | G 最小 |
| グランドカノニカル | T,V,μ | E,N | e^{−β(E_j−μN_i)}/Ξ | J(T,V,μ) = −k_BT log Ξ | J 最小 |

## (a) 文字说明（可直接用）
- **ミクロカノニカル**：孤立系。外界とエネルギー・体積・粒子数のやりとりがない。E∼E+ΔE の全微視的状態が等確率で実現する。
- **カノニカル**：温度Tの熱浴に接した系。エネルギーは変化するが V, N は固定。
- **T-p集団**：温度Tの熱浴と圧力pの圧力浴の両方に接した系。E と V が変化、N 固定。
- **グランドカノニカル**：熱浴・粒子浴に接し、T, V, μ を一定に保つ。E と N が変化。

## T-p 集团：概率最大的体积 ⇔ G 最小
- P_{n,V}：同时处于能量状态 n、体积 V 的联合概率
- 对 n 求和得体积 V 的概率（边缘概率）：P(V) = Σ_n P_{n,V} ∝ e^{−βpV} Z(T,V,N)
- Z = e^{−βF} ⇒ P(V) ∝ e^{−β[F(T,V,N)+pV]} = e^{−βG(V)}
- e^{−βG} 是 G 的单调递减函数 ⇒ dP/dV = 0 ⇔ dG/dV = 0，P 最大 ⇔ G 最小
- 宏观系统 ΔV/V ∼ 1/√N，体积实际上锁定在 G 最小的 V*

## グランドカノニカル分布の導出（拉格朗日乘数法）
记号：P_{ij} ≡ P(E_j(N_i), N_i)，i 标粒子数，j 标该粒子数下的能量状态；Σ_iΣ_j 遍历全部 (粒子数, 能量状态) 组合。

1. 目标 S = −k_B ΣΣ P_{ij} log P_{ij}；约束：ΣΣP=1，ΣΣE_jP=⟨E⟩，ΣΣN_iP=⟨N⟩
2. 𝓛 = S − α(ΣΣP−1) − β(ΣΣE_jP−⟨E⟩) − γ(ΣΣN_iP−⟨N⟩)
3. 对某一个 P_{ij} 求偏导（求和里只有同名项含它）：
   −k_B(log P_{ij}+1) − α − βE_j − γN_i = 0
4. 解出 P_{ij} = A e^{−βE_j/k_B − γN_i/k_B}，A = e^{−1−α/k_B}（每多一个约束多一个指数因子）
5. 归一化 ⇒ A = 1/Ξ，Ξ ≡ ΣΣ e^{−βE_j/k_B−γN_i/k_B}（α 被吸收）
6. 代回熵：S = k_B log Ξ + β⟨E⟩ + γ⟨N⟩（log Ξ 与 i,j 无关可提出）
7. ∂S/∂⟨E⟩ = β，∂S/∂⟨N⟩ = γ（链式法则中含 ∂β/∂E、∂γ/∂E 的项因 ∂logΞ/∂β = −⟨E⟩/k_B 全部抵消）
8. 与 dS = dE/T + p dV/T − μ dN/T 对比：β = 1/T，γ = −μ/T
9. 结果（β = 1/k_BT）：
$$P_{ij} = \frac{e^{-\beta(E_j-\mu N_i)}}{\Xi},\qquad \Xi = \sum_i\sum_j e^{-\beta(E_j-\mu N_i)}$$

Ξ 读作グザイ，比 Z 多一层对粒子数的求和。

## ⟨N⟩, ⟨E⟩ 用 Ξ 表示
- 对 μ 求导掉下 βN_i：
$$\langle N\rangle = k_BT\frac{\partial\log\Xi}{\partial\mu}\Big|_{T,V}$$
- 对 β 求导掉下 −(E_j − μN_i)，得 ⟨E⟩ − μ⟨N⟩：
$$\langle E\rangle = -\frac{\partial\log\Xi}{\partial\beta}\Big|_{\mu,V} + \mu\langle N\rangle$$

## μ_p(T), μ_T(p) 的图（理想气体）
$$\mu = k_BT\log\frac{p}{p_0(T)},\quad p_0(T) = \frac{k_BT}{\lambda_T^3}\propto T^{5/2}$$
- 等温：μ ∝ log p，单调递增、越来越平；(∂μ/∂p)_T = v > 0
- 定压：随 T 递减、上凸；(∂μ/∂T)_p = −s < 0
- 依据：d μ = −s dT + v dp（每粒子的 Gibbs–Duhem）
